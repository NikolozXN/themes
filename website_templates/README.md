# Themes

A collection of 10 premium TailwindCSS themes built with Tailwind CLI only - no CDN, no external JS frameworks.

## Features

- **10 Unique Themes**: Corporate, Portfolio, SaaS, E-commerce, Blog, Agency, Real Estate, Education, Event, and Dashboard
- **Tailwind CLI Only**: Pure Tailwind CSS compiled via CLI for maximum performance
- **Fully Responsive**: Mobile-first layouts tested across all breakpoints
- **Dark Mode Support**: Dashboard theme includes dark mode toggle
- **Production Ready**: Clean, semantic HTML with accessible semantics
- **Envato-Grade Quality**: Premium design and code quality

## Themes Included

1. **Corporate** - Enterprise-grade layouts for consulting and corporate sites
2. **Portfolio** - Dark, bold, image-first layouts for designers and studios
3. **SaaS** - Conversion-optimized landing with hero, features, and pricing
4. **E-commerce** - Product storytelling with high-CRO product cards
5. **Blog** - Editorial typography with featured stories and card grids
6. **Agency** - Gradient-rich hero with work showcase and stats
7. **Real Estate** - Search-ready hero with featured listings
8. **Education** - Course catalogs with stats and trust signals
9. **Event** - Event hero with speaker grid and CTA sections
10. **Dashboard** - Admin panel with KPI cards, charts, and dark mode

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Build CSS:
```bash
npm run build
```

3. Watch for changes:
```bash
npm run watch
```
